# ビールテイスティングクイズ

テイスターの独り言（見た目 → 香り → 味 → 後味 → アルコール感）を手がかりに、
ビールの国とスタイルを推理するブラインドテイスティング練習アプリです。地方名は正解後の参考情報として表示します。
依存ライブラリなし、静的ファイルのみ。GitHub Pages でそのまま公開できます。
16か国・99スタイルを収録しています（Version 2.6.0）。

## 使い方

`index.html` をブラウザで開くだけです（`data/styles.js` を同じ構成で置いてください）。

### GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## クイズの流れと採点

各ヒントには、技術的な官能情報に加えて、情景が浮かぶオリジナルのドラマチックなテイスティングコメントを表示します。

| 段階 | 出る情報 | やること |
|---|---|---|
| 見た目 | 色（グラスの描画＋文章）、清澄度、泡 | 候補スタイルを広めに選ぶ |
| 香り | 麦芽・酵母・ホップ | 候補を絞る |
| 味 | 麦芽・酵母・ホップ・口当たり | 候補を絞る |
| 後味 | 余韻・ドライ／甘残り・渋み | 候補を絞る |
| アルコール感 | 体感表現のみ（数値は出ない） | 候補を絞る |
| 判定 | — | 国 → スタイルを確定 |

- 各段階：正解を候補に残していれば得点。候補1つで12点、5つで4点、6つ以上で3点。外したら0点。
- 判定：国10点、スタイル30点。地方は選択・採点しません。
- 満点100点。「当てる」より「消去の精度」を鍛える配点です。

## 難易度

- **初級**：感覚表現に官能記述子を添える（バナナ → イソアミルアセテート）。3軸のラベルを表示。
- **中級**：感覚表現のみ。3軸ラベルは表示。
- **上級**：感覚表現のみ。香り・味それぞれで1軸ぶんの情報が欠ける。3軸ラベルなし。
- **全部**：問題ごとに初級・中級・上級をランダムで選び、出題時に今回の難易度を表示。

## 試験対策学習

「淡色ラガー」「英国ビター」「スタウト」「ベルギーの野生発酵・酸味」など、似たスタイルのグループを選んで学習します。
地方選択は使わず、各スタイルは国名だけを表示します。
最上部に強調表示した「見分け方：違いのポイント」で各スタイルの判定ポイントを比較します。それ以降はスタイルごとのカードにし、外観・香り・味・後味・度数・原材料・発酵方式・代表銘柄を一つにまとめて確認できます。
学習画面では、各スタイル名の上に国名を濃色のバッジで表示します。

## 候補を国単位で選択

テスト中の「候補に残すスタイル」は、各スタイル群の上にある国名を押すと、その国の全スタイルをまとめて候補に残す・外す操作ができます。国は複数選択でき、個別スタイルも追加・解除できます。
グループ内の全スタイルについて、色・香り・味・後味・度数・見分け方を同じ画面に同時表示します。
発酵方式、一般的な原材料、代表銘柄も確認でき、代表銘柄は国内通販の単品検索へ移動できます。

## 香味の由来当て

香りまたは味のコメントを読み、「麦芽」「酵母」「ホップ」のどれに主に由来するかを3択で回答します。回答後は正解の解説と、同じビールの3要素を並べて比較できます。

## D教材テスト・最頻出50

テストモードの「出題範囲」で「D教材」を選ぶと、提供されたビアソムリエ教材に掲載されたスタイルだけから出題します。「最頻出50」では、試験対策で優先して覚えたい主要50スタイルに絞って出題します。
最終回答画面では、それまでのヒントに加えて発酵方式と一般的な原材料を表示します。
正解表示と試験対策のスタイル別カードには、SRM・IBU・ABVの一般的な目安も表示します。
「日」マークはD資料の日本語ページだけに掲載されるスタイルを示します（現在の登録スタイルには該当なし）。

## スタイルを追加する

`data/styles.js` の配列にオブジェクトを追加します。

```js
{ id:"unique_id", country:"国", region:"地方", style:"スタイル名", srm:10, abv:5.0, alc:2,
  app:"見た目の描写",
  aroma:{ malt:"…", yeast:"…", hop:"…" },
  taste:{ malt:"…", yeast:"…", hop:"…", body:"ボディ・炭酸の描写" },
  after:"後味の描写",
  alcohol:"アルコール感の体感描写（数値は書かない）",
  markers:["識別ポイント1","識別ポイント2"],
  similar:["近縁スタイルのid", ...] }
```

- `srm` はグラスの色描画に使います。`app` に「濁」「霞」が含まれると濁り、「薄」「すぐ消え」などで泡が少なくなります。
- `alc` は 1〜4（ほぼ感じない〜強い温感）。復習画面以外では `abv` の数値は表示されません。
- 文中の `[感覚表現|官能記述子]` は初級で「感覚表現（官能記述子）」、中級以上で「感覚表現」だけになります。
- `markers[0]` は近縁スタイル一覧での一言説明にも使われます。

## 記録

出題数・正解率・苦手スタイルはブラウザの localStorage に保存されます（端末ごと）。ホーム画面から消せます。

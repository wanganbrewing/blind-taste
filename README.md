# BEER SENSE｜ビールスタイル鑑定

テイスターの独り言（見た目 → 香り → 味 → 後味 → アルコール感）を手がかりに、
ビールの国とスタイルを推理するブラインドテイスティング練習アプリです。地方名は正解後の参考情報として表示します。
依存ライブラリなし、静的ファイルのみ。GitHub Pages でそのまま公開できます。
16か国・99スタイルを収録しています（Version 4.5.0）。

## 日本語・English

初回はブラウザ・端末の優先言語を確認し、日本語なら日本語、それ以外なら英語で表示します。画面右上の「日本語 / English」でいつでも切り替えられ、手動で選んだ言語は同じ端末に保存されて次回も優先されます。URL の `?lang=ja` / `?lang=en` で指定した場合は、その表示を優先します。

## 初回アンケート

初回だけ、ビールとの関わり・利用目的・経験を尋ねる任意アンケートを表示します。「スキップして始める」から回答せずに利用できます。
回答者を特定する情報や氏名・メールアドレスは収集せず、集計結果は管理人だけが確認できます。回答データは Supabase に保存し、公開側には追加のみを許可して読み取りは許可しません。
管理人が `?owner=1` を付けたURLを一度開くと、その端末を管理人端末として保存し、アンケートを表示・送信しません。URLから `owner=1` は自動的に消えるため、その後は通常URLを利用できます。

## アクセス集計

同じブラウザタブの利用中は1回だけ、匿名のアクセスセッションとして記録します。保存するのは日時・表示言語・UTM流入元・入口パス・アプリバージョンだけで、氏名、メールアドレス、永続的な利用者IDは保存しません。管理人端末は記録対象外です。

## 使い方

`index.html` をブラウザで開くだけです（`data/styles.js` を同じ構成で置いてください）。

### GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## クイズの流れと採点

各ヒントには、技術的な官能情報に加えて、情景が浮かぶオリジナルのドラマチックなテイスティングコメントを表示します。
ホームのトップ画像に加え、試験の「見た目」から「判定」まで全段階で、理論派テイスター「久世 律」または感性派テイスター「香月 灯」が1人ずつ登場します。段階が進むたびに人物・表情・専用台詞が切り替わります。キャラクター画像は `assets/` に収録しています。
専用カットは4枚を交互に使います。SRMと泡持ちはキャラクター画像に重ねず、試験画面左上の可変ビールグラス直下に表示します。画像はスマートフォンでの読み込みを考慮した軽量JPEGです。
試験中は「前のヒントへ戻る」で一段階戻れます。見た目の段階では「ホームへ戻る」として動作します。
判定後は、久世 律と香月 灯が一問ごとに交互に登場します。「完全正解」「国だけ正解」「不正解」を2人分用意した合計6パターンで、正面を向いた専用画像・表情・台詞が切り替わります。

| 段階 | 出る情報 | やること |
|---|---|---|
| 見た目 | 色（グラスの描画＋文章）、清澄度、泡 | 全候補から違うものを外す |
| 香り | 麦芽・酵母・ホップ | 合わない候補を外す |
| 味 | 麦芽・酵母・ホップ・口当たり | 合わない候補を外す |
| 後味 | 余韻・ドライ／甘残り・渋み | 合わない候補を外す |
| アルコール感 | 体感表現のみ（数値は出ない） | 合わない候補を外す |
| 判定 | — | 国 → スタイルを確定 |

- 各段階：正解を候補に残していれば得点。候補1つで12点、5つで4点、6つ以上で3点。外したら0点。
- 判定：国10点、スタイル30点。地方は選択・採点しません。
- 満点100点。「当てる」より「消去の精度」を鍛える配点です。

## 難易度

- **初級**：最大12択。感覚表現に官能記述子を添え、3軸ラベルを表示。
- **中級**：最大30択。感覚表現のみ。3軸ラベルは表示。
- **上級**：選択した出題範囲の全スタイル。感覚表現のみ。香り・味それぞれで1軸ぶんの情報が欠け、3軸ラベルもなし。
- **全部**：問題ごとに初級・中級・上級をランダムで選び、ヒント量と選択肢数をその難易度に合わせます。

## 試験対策学習

「淡色ラガー」「英国ビター」「スタウト」「ベルギーの野生発酵・酸味」など、似たスタイルのグループを選んで学習します。
「国別の全体像」では16か国から選び、その国のビール文化、代表的な味・香り、発酵、試験での見分け方を最初に要約します。続けて、その国に属するスタイルを同じ画面で比較できます。
地方選択は使わず、各スタイルは国名だけを表示します。
最上部に強調表示した「見分け方：違いのポイント」で各スタイルの判定ポイントを比較します。それ以降はスタイルごとのカードにし、外観・香り・味・後味・度数・原材料・発酵方式・代表銘柄を一つにまとめて確認できます。
「見分け方」カードには、SRMに応じた色と泡量を表すミニグラスアイコンを表示します。
色だけで横断比較できる「極淡色・麦わら色」「金色」「琥珀色・銅色」「褐色」「濃褐色・黒色」の5グループも選択できます。
学習画面では、各スタイル名の上に国名を濃色のバッジで表示します。
「このグループで試験」を押すと、表示中の比較グループに含まれるスタイルだけからランダム出題します。「次の一杯」でも同じグループ限定試験を継続できます。

## 候補を国単位で選択

試験開始時は、今回の選択肢がすべて候補に残った状態です。違うスタイルを順に外します。各スタイル群の上にある国名を押すと、その国の全スタイルをまとめて外す・候補へ戻す操作ができます。
グループ内の全スタイルについて、色・香り・味・後味・度数・見分け方を同じ画面に同時表示します。
発酵方式、一般的な原材料、代表銘柄も確認でき、代表銘柄は国内通販の単品検索へ移動できます。

## 香味の由来当て

香りまたは味のコメントを読み、「麦芽」「酵母」「ホップ」のどれに主に由来するかを3択で回答します。回答後は正解の解説と、同じビールの3要素を並べて比較できます。

## D教材試験・最頻出50

試験モードの「出題範囲」で「D教材」を選ぶと、提供されたビアソムリエ教材に掲載されたスタイルだけから出題します。「最頻出50」では、試験対策で優先して覚えたい主要50スタイルに絞って出題します。
回答入力前は発酵方式と原材料を表示せず、「答える」を押した後の正解画面でのみ表示します。
正解表示、試験対策の「見分け方」、スタイル別カードには、提供教材のスタイルガイド値を優先したSRM・IBU・ABVの範囲を表示します。派生スタイルは複数ガイドの範囲を統合しています。
正解画面には、スタイルの代表的なSRM色と泡量を反映したビアグラスアイコンも表示します。
「日」マークはD資料の日本語ページだけに掲載されるスタイルを示します（現在の登録スタイルには該当なし）。

## スタイルを追加する

`data/styles.js` の配列にオブジェクトを追加します。

```js
{ id:"unique_id", country:"国", region:"地方", style:"スタイル名", srm:10, abv:5.0, alc:2,
  app:"見た目の描写",
  aroma:{ malt:"…", yeast:"…", hop:"…" },
  taste:{ malt:"…", yeast:"…", hop:"…", body:"ボディ・炭酸の描写" },
  after:"後味の描写",
  alcohol:"アルコール感の体感描写（数値は書かない）",
  markers:["識別ポイント1","識別ポイント2"],
  similar:["近縁スタイルのid", ...] }
```

- `srm` はグラスの色描画に使います。`app` に「濁」「霞」が含まれると濁り、「薄」「すぐ消え」などで泡が少なくなります。
- `alc` は 1〜4（ほぼ感じない〜強い温感）。復習画面以外では `abv` の数値は表示されません。
- 文中の `[感覚表現|官能記述子]` は初級で「感覚表現（官能記述子）」、中級以上で「感覚表現」だけになります。
- `markers[0]` は近縁スタイル一覧での一言説明にも使われます。

## 記録

出題数・正解率・苦手スタイルはブラウザの localStorage に保存されます（端末ごと）。ホーム画面から消せます。
